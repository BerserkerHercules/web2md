01政策适用范围

本政策适用于 iOS 应用「脑力健身房」（以下简称“本应用”）。本应用为一款认知训练工具，提供多种注意力、工作记忆与执行功能训练小游戏、训练数据统计、成就系统与可选的 iCloud 同步。

请你在使用本应用前仔细阅读本政策。当你开始使用本应用，即表示你已理解本政策所述内容。本应用的设计遵循“能不收集就不收集、能不出端就不出端”的原则。

02我们收集与使用的信息

本应用不要求注册账号，不会索取你的姓名、手机号、电子邮箱、地理位置、通讯录、照片（保存成就图片除外，见下）等身份信息，也不读取广告标识符（IDFA）。实际涉及的数据如下：

2.1 数据类型一览

数据类型具体内容使用目的存放位置
训练记录与设置 每局游戏的分数、正确率、反应时长等表现数据；难度、每日训练与打卡记录、成就、偏好设置。不含任何身份信息。 在本机生成统计图表、自适应难度与成就 默认仅本机
购买记录 非消耗型买断商品（unlockAll）的交易权益状态。支付由 Apple 处理，开发者无法接触你的付款信息 验证你已购买的完整功能权益（含 iCloud 同步） Apple StoreKit

2.2 设备权限

  • 通知（默认关闭）：仅用于在你设定的时间发送每日训练提醒。提醒由 iOS 本地通知调度，不联网、不上传，通知内容不含任何成绩或身份信息。你可以随时在应用设置或系统设置中关闭。
  • 相册（仅“添加”权限）：仅当你主动保存或分享成就图片时，经你确认后把图片写入相册。本应用不能读取或浏览你的相册内容。

2.3 我们明确不做的事

  • 不接入任何广告 SDK、广告归因或数据分析 SDK；
  • 不使用 IDFA / 广告标识符，不进行跨应用追踪；
  • 不收集设备型号、系统版本、IP 地址等用于画像的信息；
  • 不索取位置、通讯录、麦克风、相机、健康等权限。
  • 不将你的训练数据发送至开发者或任何第三方的服务器。

03数据存储与处理方式

本应用的全部训练数据统计、图表与自适应难度计算均在这台设备上完成：

  1. 本机处理：每一局的分数、正确率、反应时长都记录在本机应用沙盒内的 JSON 文件中，统计与难度调整在你的设备上实时计算；
  2. 本机存储：这些文件不上传至开发者，也不进入任何开发者控制的服务器；
  3. 唯一的云端：当你购买完整功能并手动开启 iCloud 同步后，训练数据会通过 Apple CloudKit 私有数据库在你的多台 Apple 设备间同步，存储于 Apple 的基础设施，开发者与其他任何用户均无法访问（详见下一节）；
  4. 唯一的交易通道：应用内购买由 Apple StoreKit 完成，开发者只收到交易结果，不接触你的付款信息。
简而言之：你的训练数据只存在于你的设备与 Apple 为你提供的 iCloud 私有库里，开发者看不到、也无法导出。

04iCloud 云同步

iCloud 同步是买断用户的可选功能，用于在你自己的多台 Apple 设备间同步训练数据。它满足以下全部条件时才会运行：你已购买完整功能、已在设置中手动开启、设备已登录 iCloud。免费用户或开关关闭时，应用不会发起任何云同步请求。

  • 同步使用 Apple CloudKit 私有数据库，数据与你的 Apple ID 关联，仅你本人可访问，开发者与其他任何用户均无法查看；
  • 同步内容为训练记录、打卡、成就、难度与偏好设置的 JSON 数据；
  • 你可以在应用设置中随时关闭同步，或使用“清空本机与 iCloud 云端”彻底删除两端数据。

本应用不向任何第三方共享、出售或出租你的个人信息。唯一的服务提供方是 Apple：

服务提供方使用场景收到的信息
Apple
（StoreKit / CloudKit / 系统通知）		 内购交易与权益验证、iCloud 私有数据库同步、本地通知调度 交易信息与 iCloud 数据由 Apple 按其隐私政策处理，开发者不可见你的付款信息

上述服务提供方对其自身服务收集的信息承担独立责任，你可以查阅 Apple 的隐私政策了解更多。我们不会出于广告或营销目的向任何方共享数据。

06存储地点与留存期限

  • 本机数据：以 JSON 文件形式保存在你的设备应用沙盒内，不上传至开发者服务器；
  • iCloud 数据：存储于 Apple CloudKit，数据区域由 Apple 根据你的 Apple ID 设置管理；
  • 留存期限：训练数据在你设备上保留至你主动删除（应用内“清空数据”）或卸载应用；开启 iCloud 同步的数据保留至你执行“清空本机与云端”。

07数据安全

  • 训练数据以 JSON 文件形式保存在应用沙盒内，受 iOS 的应用隔离保护；
  • iCloud 数据通过 Apple 系统机制加密传输与存储；
  • 内购交易验证由 Apple 的 StoreKit 完成，开发者不存储你的付款信息。

如发现安全问题，欢迎通过下方联系方式告知，我们会及时处理。

08你的权利

依照《中华人民共和国个人信息保护法》等相关法律法规，你享有以下权利：

  • 查阅与导出：可在应用设置中导出你的训练记录（JSON 文件，经系统分享面板由你自行选择去向）；
  • 删除：可随时在应用内清空本机数据；开启 iCloud 同步时可一并清空云端数据；卸载应用也会删除本机全部数据；
  • 撤回同意：可随时关闭通知或 iCloud 同步开关；关闭同步后，本机数据不再上传云端；
  • 注销账号：本应用无账号体系，因此无需注销；
  • 投诉与举报：如认为我们处理个人信息损害了你的合法权益，可通过下方邮箱联系，我们将在 15 个工作日内回复。

09未成年人保护

本应用为通用认知训练工具，不针对不满 14 周岁的儿童设计，也不主动收集未成年人的个人信息。由于应用无需注册且不收集身份信息，我们无法识别用户年龄。若你是监护人，发现未成年人在未获你同意的情况下使用相关功能，可通过应用内删除功能清除其数据，或联系我们协助处理。
